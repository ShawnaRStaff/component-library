Prose Container (Optimal Reading Width)

Article Title

The prose container sets an optimal line length for reading (65 characters). This makes long-form content much easier to read by preventing lines from becoming too long.

Studies show that the optimal line length for reading is between 45-75 characters per line. The prose container enforces this by setting a max-width based on character count rather than pixels.

Prose Sizes

prose--sm (45ch) - For tighter layouts or sidebars

prose--lg (80ch) - For wider content areas, code blocks, etc.
